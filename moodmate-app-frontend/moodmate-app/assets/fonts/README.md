# Required fonts

Download Quicksand from Google Fonts:
https://fonts.google.com/specimen/Quicksand

Required weights: Light (300), Regular (400), Medium (500), SemiBold (600), Bold (700)

Place the .ttf files here with these exact names:
- Quicksand-Light.ttf
- Quicksand-Regular.ttf
- Quicksand-Medium.ttf
- Quicksand-SemiBold.ttf
- Quicksand-Bold.ttf
